How to use Lime Boost Starter

Lime Boost Starter is an open-source application that demonstrates how to build an application using AWS services deployed and configured by Lime Boost. Lime Boost itself is proprietary software.

  1. Create an AWS account

    Lime Boost deploys infrastructure directly into your AWS account. You own the AWS resources and can also view and manage them through the AWS Console.

  2. Open Lime Boost and connect AWS

    Sign in to app.limeboost.io and follow the account setup instructions. This allows Lime Boost to deploy and configure AWS infrastructure on your behalf.

  3. Deploy the AWS services

    In Lime Boost: Choose the infrastructure your application needs. For Lime Boost Starter, you can deploy:

    • Cognito Provides authentication for the Starter application, including registration, sign-in, password reset, and authenticated sessions.
    • CloudFront Deploys the built Angular application and delivers it securely over HTTPS.
    • DynamoDB + API Gateway Provides a serverless database and HTTPS API that the Starter application can use to store and retrieve data.
    • Amazon Bedrock AgentCore Provides infrastructure for running production AI agents.

      Lime Boost can also deploy supporting AWS services such as Route 53 for domains and other infrastructure required by your application.
